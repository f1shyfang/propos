Title: Demo Script - Buyer's Agent E2E Presenter Script
Date: 2026-05-24

Purpose
-------
Concise presenter script for a complete buyer's agent end-to-end demo. This file contains the minimal UI actions and single-line presenter cues for each phase so the demo is fast, reliable and easy to follow.

Setup cue
---------
Agent window: http://localhost:3000 (signed in as Agent).
Client window (Incognito): http://localhost:3000/portal (signed in as Sarah).

Phase 0 - Opening pitch (10-15s)
- What happens: Agent dashboard is visible.
- Actions (UI): Show dashboard overview.
- Say: "We'll run the full buyer's-agent lifecycle in Propos: brief -> match -> shortlist -> CMA/valuation -> agent outreach -> offer negotiation -> due diligence -> unconditional acceptance -> invoice generation - all in one platform."

Phase 1 - Create brief & set strategy (60s)
- What happens: Create a structured buyer brief that feeds the engine.
- Actions (UI): Visit /briefs/new -> Click "New Buyer Brief" -> Fill: Client = "Sarah & Tom", Budget = 800000-1100000, Suburbs = Surry Hills, Newtown, Pyrmont, Type = Apartment, Beds >= 2, Must-have = balcony, Deal-breaker = ground floor, Pre-approval = Pre-Approved -> Click Create -> Open brief detail.
- Say: "A structured brief becomes the system's single source of truth for this client."

Phase 2 - Matching & triage (60s)
- What happens: System shows scored matches for the brief.
- Actions (UI): Open /briefs/<id>/matches -> Point to top matches, open 2-3 property cards and the Match tab to show score breakdown (Budget / Location / Features).
- Say: "Matches are pre-scored by budget, location and features so agents immediately see best opportunities - and why they rank there."

Phase 3 - CMA / Valuation (60-90s)
- What happens: Produce comparables and a CMA PDF for the lead property.
- Actions (UI): Click the lead property (e.g. "42 Union Street") -> /properties/<id> -> Open CMA tab -> Click "Generate CMA" (or open pre-generated PDF at /demo_reports/cma_42_union.pdf). Show 2-3 comparables.
- Say: "Here's the agent's valuation support - comparables, a price range and commentary to show the client before we make an offer."

Phase 4 - Contact / Outreach to selling agent (30-60s)
- What happens: Reach out to the listing agent with an anonymised buyer brief.
- Actions (UI): From property detail open Listing Agent card -> Click "Contact Agent" -> Choose template "Intro + Anonymised buyer brief" -> Send -> Open Activity Feed to show outreach logged.
- Say: "We contact the selling agent with an anonymised brief - that often uncovers off-market opportunities or speeds negotiations."

Phase 5 - Shortlist & share with client (30-45s)
- What happens: Shortlist the property and share it to the client portal.
- Actions (UI): Click "Add to Shortlist" -> Select client -> Click "Share with Client". Switch to client window and show shortlist entry appear.
- Say: "I curate the shortlist and push it directly into Sarah's portal so she can review in context."

Phase 6 - Client feedback (45-60s)
- What happens: Client gives structured feedback which syncs to the agent.
- Actions (UI): In client portal open shortlist property -> Click "Interested" and add comment "Love the balcony - inspect weekend?"; mark another as "Not For Me". Switch back to Agent dashboard - show feedback badge and timeline entry.
- Say: "Client feedback syncs instantly - agent sees it and can act immediately."

Phase 7 - Create Deal & Generate Offer Letter (60-90s)
- What happens: Turn interest into a deal and send an offer.
- Actions (UI): From shortlist row click "Create Deal" -> In Deal view open Offer generator -> Choose template (Private Sale), enter Offer 950000, Deposit 95000, Conditions = subject to finance + building & pest -> Click "Send Offer". Open Offer history.
- Say: "Offer sent - every offer and counter is recorded so negotiation is auditable."

Phase 8 - Negotiation & Counter Offers (45-90s)
- What happens: Record vendor counter-offer and agent response.
- Actions (UI): Show Offer history in deal view (simulate vendor counter then agent counter). Highlight timestamps and notes.
- Say: "All counters are tracked with rationale - no lost threads, full audit trail."

Phase 9 - Offer Accepted -> Under Contract (45-60s)
- What happens: Accepted offer becomes Under Contract and milestones are created.
- Actions (UI): Mark offer Accepted -> Deal status flips to "Under Contract" -> Open deal to show autogenerated milestones (Book building & pest, Conveyancer review).
- Say: "Offer accepted - settlement timeline and due-diligence checklist are now active."

Phase 10 - Due Diligence (quick cuts, 2-4 min)
- What happens: Run checks (building & pest, strata, finance, conveyancer).
- Actions (UI): In deal's Due Diligence tab mark "Building & Pest" done, upload contract PDF to Document Vault (/demo_reports/contract_42_union_signed.pdf), mark finance approved. Show checklist progress.
- Say: "Due diligence items are tracked and evidence is stored so the team knows exactly what's done."

Phase 11 - Remove conditions -> Unconditional acceptance (30-60s)
- What happens: Conditions cleared and offer becomes unconditional.
- Actions (UI): Update offer to "Unconditional" -> Deal status -> "Unconditional". Show milestone completion.
- Say: "All conditions satisfied - the offer is now unconditional and we can issue the final fee."

Phase 12 - Generate Final Invoice (30-60s)
- What happens: Produce the final invoice PDF for the client.
- Actions (UI): In deal view click "Generate Invoice" -> Open invoice preview (e.g. /demo_reports/invoice_42_union.pdf).
- Say: "Final invoice generated as a download-ready PDF - payments are out of scope for this demo."

Phase 13 - Closing & evidence (30s)
- What happens: Show the full audit trail and documents.
- Actions (UI): Open Activity Feed and Document Vault (CMA, signed contract, invoice) for the deal. Highlight timeline.
- Say: "Everything - brief, matches, CMA, outreach, offers, due diligence and invoices - is in one place and fully auditable."

Presenter tips (one-line each)
- Keep two browser windows side-by-side (Agent | Client) to switch quickly.
- Use the prepared PDFs in public/demo_reports so PDF views load instantly.
- If a live UI action fails, jump to the pre-seeded deal view (Under Contract) and continue the narrative.
